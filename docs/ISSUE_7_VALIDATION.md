# Issue #7：AirPlay 专辑封面

## 修复范围

原实现只发送曲目文本，没有使用 `Track.Cover`。现在后台获取封面，向 cliairplay 提交私有本地图片文件。HomePod 与晚加入的 Apple TV 共用下载缓存；暂停恢复、切歌和重连会应用当前曲目的封面。下载失败不阻断 PCM 或文本元数据，管理诊断只包含固定原因，不记录 URL、查询参数或引擎原始输出。

## 固定引擎接口

实现针对仓库使用的 cliairplay **v0.5.3**，没有升级引擎。依据 [该版本 README](https://github.com/music-assistant/airplay-cli/blob/v0.5.3/README.md)、[命令解析](https://github.com/music-assistant/airplay-cli/blob/v0.5.3/src/cliairplay.c) 和 [图片加载实现](https://github.com/music-assistant/airplay-cli/blob/v0.5.3/src/artwork.c)：

- `ARTWORKFILE=<绝对文件路径>` 暂存图片，随后 `ACTION=SENDMETA` 将图片与文本一同提交，并消费暂存路径。Spotify 的 HTTPS URL 由 Go 下载，不直接传给引擎。
- 普通文本更新显式发送空 `ARTWORKFILE=`，避免残留暂存路径。下载完成后，使用最新文本和进度提交图片；同一曲目和封面不会因进度或音量更新而重复提交图片。
- 新 `ITEMID` 的元数据会清除旧 MediaRemote 封面。对同一曲目撤掉或替换封面，使用空 `ARTWORK=`：v0.5.3 的空源处理会调用 `ap2cl_clear_mrp_artwork`。这不是 `ARTWORKFILE=` 的清除暂存行为。引擎可能报告 `artwork=rejected`，应用仅记录“引擎已省略或清除封面”。
- 上述清除能力针对 Apple 的 MediaRemote 路径；v0.5.3 没有通用的 RAOP/DMAP 封面清除命令，不能保证旧式接收器会清除已有封面。
- 原生 Apple MediaRemote 只接收 JPEG，内部图片暂存限制为 1 MiB。应用完整解码验证图片，保留合适的 JPEG，将 PNG 或过大的 JPEG 尝试转为 JPEG；仍超过发送上限则跳过。

## 下载、缓存和时序

- 仅接受 HTTPS、默认端口 443、无用户信息的 URL；拒绝 fragment。最长 8192 字节，最多三次重定向，每次重新检查 URL。
- 总下载期限五秒，响应头最多 16 KiB，图片下载最多 5 MiB。校验 HTTP 状态、JPEG/PNG Content-Type、实际格式、完整解码及像素上限：单边不超过 4096，总计不超过 4,194,304 像素。
- 连接前检查全部解析地址，拒绝 loopback、私网、链路本地、共享地址和保留地址；直接连接通过检查的 IP，TLS 仍校验原域名。禁用环境代理，避免绕过目标地址检查。
- 内存缓存最多八项，成功保留十分钟、失败保留三十秒；同 URL 的并发请求共享一次下载。最后一个使用者取消后，取消请求；取消结果不污染新请求。
- 每个发送器一个后台工作协程。曲目/封面变化、清空、待机和关闭会使旧任务失效；下载完成后在控制命令锁内复查代次，旧任务不能回写新曲目。无封面时取消在途下载并清除可清除的旧封面。
- 临时目录权限 0700、图片 0600，路径不包含远端输入。每次提交使用独立文件，不覆盖已交给引擎的文件。每个发送器最多保留最近八张，子进程退出后清理目录。引擎严重落后时可能读不到已淘汰的旧文件，但不会把新图片当作旧曲目的图片读取。

## 自动验证

`go test -race ./...` 和 `go vet ./...` 覆盖下载失败、超时、类型/大小/损坏图片、重定向到本机和私网、共享缓存与取消、快速切歌、空封面、发送失败、临时文件回收，以及组合晚加入和加入途中切歌。

子进程集成测试在阻塞封面下载时确认 PCM 已触发 START，并实际读取 FIFO 中指定的图片文件、校验内容摘要；同时覆盖暂停恢复与重连后的再次提交。模拟引擎测试不等同于 Apple TV 显示验收。

- [ ] 有封面的 Spotify 曲目：HomePod 正常出声，Apple TV 显示对应专辑封面。
- [ ] HomePod 先播放、Apple TV 后加入：晚加入后显示当前封面。
- [ ] 不同专辑连续切歌、快速切歌：最终封面与当前曲目一致，不回写旧封面。
- [ ] 无封面或下载失败：音频和文本继续，Apple MediaRemote 不保留上一曲封面。
